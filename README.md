# Top Robbers

Community hub, roadmap, suggestions, and project coordination for **Top Robbers**.

**Top Robbers** is an open-source Cops & Robbers gamemode for open.mp, showcasing modern GTA multiplayer development with SampSharp (C#), omp-cef, and CEF-powered interfaces.

## About this repository

This repository is used for:

- Project discussions
- Community suggestions
- Roadmap tracking
- Feature planning
- Balance feedback
- Cross-repository coordination
- Public decisions and announcements

Technical bugs should usually be reported in the relevant repository below.

## Project repositories

- `gamemode` — open.mp / SampSharp C# gamemode
- `webview` — CEF-powered in-game UI with React
- `launcher` — desktop launcher and updater
- `locales` — shared translation files
