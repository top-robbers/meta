# Code of Conduct

## Our pledge

We want **Top Robbers** to be a respectful, constructive, and welcoming open-source community.

Everyone is expected to help keep the project friendly, useful, and focused.

## Expected behavior

Examples of positive behavior include:

- Being respectful and constructive
- Helping others when possible
- Giving clear feedback
- Accepting different opinions
- Staying on topic
- Crediting contributors and open-source work
- Reporting issues responsibly

## Unacceptable behavior

The following behavior is not allowed:

- Harassment, threats, or personal attacks
- Hate speech or discriminatory language
- Trolling, spam, or intentionally disruptive behavior
- Publishing private information without permission
- Sharing malware, cheats, stolen assets, leaked files, or illegal content
- Encouraging abuse, exploitation, or attacks against servers or players
- Claiming someone else’s work as your own
- Repeatedly ignoring moderator or maintainer instructions

## Project-specific expectations

Top Robbers is related to GTA multiplayer modding, open.mp, SampSharp, CEF, and open-source tooling.

The following are not allowed in official project spaces:

- Pirated game files
- Stolen assets
- Cheat tools
- Token leaks
- Credential leaks
- Exploit instructions against public servers
- Harassment toward other communities or projects

## Enforcement

Maintainers and moderators may take action when this Code of Conduct is violated.

Actions may include:

- Warning
- Message removal
- Issue or discussion locking
- Temporary mute or ban
- Permanent ban
- Removal from contributor roles
- Reporting severe abuse to relevant platforms

## Reporting

If you need to report unacceptable behavior, contact the project maintainers privately on Discord.

## Scope

This Code of Conduct applies to:

- GitHub repositories
- GitHub issues
- GitHub discussions
- Pull requests
- Discord
- Community spaces officially linked to the project
- Public interactions related to the project

## Attribution

This Code of Conduct is a simple project-specific policy inspired by common open-source community standards.
