# Top Robbers - Roadmap

This roadmap describes the current direction of the **Top Robbers** project.

It is not a fixed promise. Priorities may change depending on technical constraints, contributors, community feedback, and testing results.

## Vision

Top Robbers aims to be an open-source Cops & Robbers gamemode for open.mp, built around arcade-style gameplay, pursuits, robberies, crews, racing activities, territories, progression, and modern CEF-powered interfaces.

---

## Phase 0 — Foundation

Status: In Progress

Goals:

- Repository setup
- Project structure
- Contribution guidelines
- License setup
- Discord / GitHub organization
- Roadmap and issue triage workflow
- Basic localization structure
- Initial coding conventions

Target repositories:

- `meta`
- `locales`
- `gamemode`
- `webview`
